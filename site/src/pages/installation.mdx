# Installation

Install `bazel-language-server` somewhere on the editor's `PATH`. Bazel is
optional; Bazel-backed features require version 8.0 or newer. Formatting and
lint diagnostics require `buildifier`.

## Cargo

Requires Rust 1.85 or newer.

```sh
cargo install bazel-language-server
```

## Nix

Run directly:

```sh
nix run github:barrettruth/bazel-language-server
```

Or add the package to a flake:

```nix
inputs.bazel-language-server.url = "github:barrettruth/bazel-language-server";
```

## From source

```sh
git clone https://github.com/barrettruth/bazel-language-server.git
cd bazel-language-server
cargo install --path . --locked
```

## Neovim

Using Neovim's built-in LSP client:

```lua
vim.filetype.add({
  filename = { ['.bazelrc'] = 'bazelrc' },
  pattern = { ['.*%.bazelrc'] = 'bazelrc' },
})

vim.lsp.config('bazel_ls', {
  cmd = { 'bazel-language-server' },
  filetypes = { 'bzl', 'bazelrc' },
  root_markers = {
    'MODULE.bazel',
    'REPO.bazel',
    'WORKSPACE.bazel',
    'WORKSPACE.bzlmod',
    'WORKSPACE',
    '.git',
  },
  workspace_required = false,
})

vim.lsp.enable('bazel_ls')
```

For another editor, start `bazel-language-server` over stdio for its Bazel or
Starlark file type and use `bazelrc` for `.bazelrc` and `*.bazelrc`. No command
arguments are required.

See [Configuration](/configuration.html) for Bazel settings and
[Features](/features.html) for the available capabilities.
